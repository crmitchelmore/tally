# Store artwork

`google-play-feature.svg` is the editable source for the 1024 × 500 Play feature graphic. Its PNG export was visually checked and uploaded to the English (UK) draft listing.

Regenerate from `tally-web/` with:

```sh
node -e 'require("sharp")("../assets/store/google-play-feature.svg").png().toFile("../assets/store/google-play-feature.png")'
```

The existing `assets/icons/icon-512.png` is used for the Play icon. Actual app screenshots are generated by the manual Store Screenshots workflow, using fictional goals in local mode. Choose `all`, `ios` or `android`; Android captures at 1080 × 1920, while iOS uses the available Pro Max and 13-inch iPad simulators. Inspect the output before uploading it; passing instrumentation alone does not prove the screenshot shows the settled screen.
